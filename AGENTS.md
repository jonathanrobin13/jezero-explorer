# Jezero Explorer

Jezero Explorer is a NASA Space Apps Challenge project. Build an interactive map that helps a visitor explore evidence of ancient water in Jezero Crater and plan a terrain-aware Marswalk to a science destination.

## Start with the challenge resources

- Open the **Resources** tab on the official [Interplanetary Survival Guide: Martian Map challenge page](https://www.spaceappschallenge.org/2026/challenges/interplanetary-survival-guide-martian-map/?tab=resources) before choosing datasets or preparing submission materials. Consult the official challenge prompt for scope and check the current submission guidance.
- Read the relevant files in `resources/` for the local event timeline, challenge requirements, submission instructions, and project notes. Use and cite at least one NASA resource listed for the challenge if pursuing global award eligibility.
- Record the mission, instrument, product identifier, publisher, source link, resolution, and coverage for each dataset used. Check actual overlap with the selected science stop and route before integrating a layer.

## Work like a senior NASA engineer

- Apply the judgment of a senior NASA engineer mentoring a developing engineer. Tie decisions to the science objective, user needs, data quality, and available build time. Explain meaningful trade-offs and make assumptions explicit.
- Verify coordinate systems, units, raster alignment, resolution, and missing data before calculating slopes or distances. Treat routes as prototype terrain assessments and show where the model has insufficient coverage.
- Keep measured observations, scientific interpretations, and modeled outputs distinct. Describe what the evidence suggests about ancient water and preserve its provenance. Label environmental observations with their measurement location and time.
- Inspect the existing project before editing. Favor incremental changes and verify the main user flow with real data. Use Python for geospatial processing and React for the interface where those choices fit the project. Prioritize the 2D map, a sourced science stop, and user-selected routing. Treat 3D as a stretch goal.

## Build toward a NASA career

- Use this project to practice and demonstrate planetary data analysis, scientific computing, systems thinking, verification, and clear technical communication.
- Explain the reasoning behind consequential decisions so the project owner can discuss and defend them independently. Connect the math and code to the Marswalk scenario.
- Capture key decisions, validation results, and known limitations as the project develops. For portfolio materials, credit data and tools accurately and describe the project owner's specific contributions, including what they implemented, tested, and learned.
